# WordMomo 🍑

> 漸進式英語學習網站 — 由**單字 → 詞組 → 句子 → 完整段落**，用打字的方式把英文真正打出來。
> 純 HTML / CSS / JavaScript，不需要安裝任何東西，開瀏覽器就能用。

🌐 **線上版**：<https://joshua19683721.github.io/wordmomo/>

---

## ✨ 核心玩法

每一條「漸進鏈」是一組由簡到難的練習：

```
This                        = 這                      = /ðɪs/
This is                     = 這是                    = /ðɪs ɪz/
not planned                 = 未預先計劃的            = /nɑːt plænd/
This is not planned         = 這不是預先計劃好的      = /ðɪs ɪz nɑːt plænd/
Oh no, this is not planned  = 噢不，這完全不在計劃中  = /əʊ nəʊ, ðɪs ɪz nɑːt plænd/
Mr. President               = 總統先生                = /ˈmɪstər ˈprezɪdənt/
```

練習畫面**只顯示 中文 → 音標 → 喇叭**，英文答案完全看不到，由你回想並一個字一個字打出來：

```
              這個樂團是
             /ðɪs bænd ɪz/
                 🔊
       ┌────────────────────────┐
       │  把英文打出來，按空白鍵送出這個字  │
       └────────────────────────┘   第 1 / 3 個字

  空白 送出這個字 · Ctrl+' 播放發音 · Ctrl+; 顯示答案 · Enter 送出
```

| 規則 | 行為 |
|---|---|
| **答案隱藏** | 目標英文不出現在畫面上，也不出現在網頁原始碼裡 |
| 空格佔位 | 沒打的字只留一個虛線空格，不透露內容也不透露長度 |
| 打字音效 | 每敲一個字都有「咔哒」聲（Web Audio 即時合成，不用音檔） |
| 空白鍵 | 送出目前的字 → 正確就**唸出這個字**、標綠顯示、跳下一個 |
| **打錯** | 該槽位**標紅並停在原地**，發出錯誤音，游標不會前進 |
| 重打 | 輸入框自動全選，刪掉重打正確的才能繼續往下打 |
| 整句完成 | 這一句**完整顯示出來**並把整串再唸一次 |
| `Ctrl` + `'` | 隨時重播目前這句的發音（等同點喇叭） |
| `Ctrl` + `;` | **顯示答案**，卡住時可以偷看，看完繼續打 |
| 標點 | 逗號、句號、分號在完成後自動顯示，不用打 |
| 大小寫 / 撇號 | 不影響判定（`don't` 打成 `dont` 也算對） |

> 設定裡可以關掉「打完一個字就顯示它」，改成**整句打完才顯示**。

## 📚 字庫管理（可新增／修改／刪除）

到 **字庫** 頁就能：

- **＋ 新增字庫** — 自己取名（預設叫「自定義1」）、選圖示、設等級（A1～C2）
- **✎ 編輯內容** — 編輯漸進鏈與步驟：新增／刪除／上下移動鏈與步驟，每個步驟分別填英文、中文、音標
- **🗑 刪除** — 連同學習紀錄一起移除
- **匯出成 data.js** — 把目前的字庫輸出成 JS 片段
- **還原內建字庫** — 一鍵回到出廠狀態

> 內建的 5 個字庫（200 條漸進鏈）**也可以直接改**，改動會存進你的瀏覽器。

### 自訂字庫怎麼保存

新增的字庫存在**瀏覽器本地**（localStorage），不會自動進 GitHub。
要讓它變成所有裝置共用的固定版本：

1. 字庫頁 → **匯出成 data.js** → 複製（或直接下載）
2. 貼回專案的 `js/data.js` 取代舊內容
3. `git push`

## 📁 檔案結構

```
wordmomo/
├── index.html                    ← 頁面骨架（導覽列、四個頁面、設定抽屜、編輯視窗）
├── css/
│   └── style.css                 ← 全部樣式，分 1~9 個區塊
├── js/
│   ├── data.js                   ← ★ 內建字庫（漸進鏈內容）
│   ├── core.js                   ← 斷詞比對、打字音、字庫 CRUD、進度、統計
│   └── app.js                    ← 四個頁面的畫面與互動
├── assets/favicon.svg
├── .github/workflows/pages.yml   ← push 到 main 自動部署
├── LICENSE
└── .gitignore
```

**怎麼改東西：**

| 想改什麼 | 改哪個檔案 |
|---|---|
| 加單字／改內容 | 網頁上的「字庫」頁，或直接編輯 `js/data.js` |
| 改打字判定規則 | `js/core.js` 的 `WM.text` |
| 改打字音效 | `js/core.js` 的 `WM.audio` |
| 改畫面與互動 | `js/app.js` |
| 改配色、圓角、間距 | `css/style.css` 最上面的「設計變數」 |

## ✏️ data.js 資料格式

```js
window.WORDMOMO_DATA = {
  version: 2,
  packs: [
    {
      id: 'demo',            // 唯一代碼
      name: '自定義1',        // 字庫名稱（可自由命名）
      icon: '🎯',
      level: 'B1',
      desc: '說明文字',
      chains: [              // 漸進鏈
        {
          id: 'demo-001',
          steps: [           // 由簡到難的步驟
            { en: 'This',   zh: '這',   ipa: '/ðɪs/' },
            { en: 'This is', zh: '這是', ipa: '/ðɪs ɪz/' }
          ]
        }
      ]
    }
  ]
};
```

`ipa` 可以留空字串（整句通常不標音標，畫面會改顯示「用發音按鈕聽」）。

## 🔊 發音引擎

Windows 上同時有兩種引擎，可以在 **⚙ 設定** 裡選：

| 供應商 | 性質 | 內容 |
|---|---|---|
| **Microsoft 微軟** | **離線**，零延遲、不吃網路 | David / Zira / Mark（美式） |
| **Google 谷歌** | **線上**，需要網路 | US English、UK English Female / Male |

- 選「**自動**」時優先用離線的 Microsoft
- 換供應商會清掉指定的語音，讓引擎偏好真正生效
- 線上語音斷網或逾時會**自動改用微軟語音**重試一次
- 設定頁下方會顯示「目前會用哪一個」

> 語音清單來自瀏覽器／作業系統，換電腦看到的清單可能不同。
> 要新增 Google 語音，可在 Windows 設定 → 語言 → 新增語音並安裝語音套件。

## 🧱 技術說明

- 沒有框架、沒有建置步驟、沒有依賴套件
- 發音：Web Speech API（`speechSynthesis`），支援 Microsoft / Google 引擎切換
- 打字音：Web Audio API 即時合成
- 練習時答案不寫進 HTML（喇叭按鈕用代號，點擊時才解析），檢視原始碼也看不到答案
- 儲存：`localStorage`，單一鍵 `wordmomo.v2`，資料留在使用者裝置
- 繁體中文（台灣用字）
